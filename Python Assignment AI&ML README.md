# Student Social Media Addiction Record Manager

## Project Title

Student Social Media Addiction Record Manager

## Description

This Python mini project analyzes student social media usage using a
real-world dataset. The application loads student data from a CSV file,
converts it into a list of dictionaries, and provides a menu-driven
console interface to view records, search students, calculate average
usage, and save results to a new file. The project strictly follows the
Python Mini Project Assignment Guide.

## Dataset Used

* File Name: Students Social Media Addiction.csv
* Description: Contains student details such as gender, daily social
  media usage hours, and academic performance.

## Features

* Load data using pandas
* Convert DataFrame into list of dictionaries
* View all student records
* Search students by gender
* Calculate average daily social media usage
* Save processed data to a new CSV file
* Menu-driven program with error handling

## Concepts Used

* pandas library
* Lists and dictionaries
* User-defined functions
* Conditional statements (if / elif / else)
* While loop
* String methods
* Dictionary methods
* Exception handling
* File handling

## Steps to Run the Program

1. Open Jupyter Notebook
2. Place the dataset file in the same folder
3. Run each step cell-by-cell
4. Use menu options to interact

## Menu Options

1. View all students
2. Search students by gender
3. Show average daily usage
4. Save records to file
5. Exit

## Output Files

* Student\_Addiction\_Output.csv
